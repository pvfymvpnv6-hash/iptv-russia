# iptv-russia

Alle russischen Sender aus [iptv-org](https://github.com/iptv-org/iptv) in einer Gruppe **„Russia Neu“** für Kodi (PVR IPTV Simple Client).

- Enthält **alle** verfügbaren Streams pro Sender, nicht nur einen. Läuft eine Version nicht, steht die nächste direkt darunter.
- Namen in lateinischer Schrift, mit Logos.
- Streams, deren Server-Adresse nicht mehr existiert, werden automatisch entfernt.
- Wird jeden Morgen automatisch neu gebaut.

**Playlist-URL für Kodi:**

```
https://raw.githubusercontent.com/pvfymvpnv6-hash/iptv-russia/main/russia.m3u
```
